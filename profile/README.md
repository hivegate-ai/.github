# HiveGate

**Open-source production runtime for AI agents, built on [Agno](https://github.com/agno-agi/agno).**
Create, configure, version and chat with agents over HTTP. Compose them into teams, connect them to
Gmail, Calendar and Drive, and deploy with one click. MIT licensed.
